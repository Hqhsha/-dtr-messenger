# дтр — мессенджер

Репозиторий для переноса исходного проекта личного мессенджера.

## Планируемые возможности
- Регистрация и вход по уникальному логину и паролю; email необязателен.
- Поиск пользователей по логину.
- Личные чаты 1-на-1, история и статусы прочтения.
- Текстовые сообщения и эмодзи.
- Профиль пользователя: отображаемое имя, описание и аватар.
- Адаптивный интерфейс.
- Аудио- и видеозвонки — будущий этап на WebRTC.

## Технический контекст
Исходная версия создана на Floot и использует React, серверные endpoint-ы Floot, PostgreSQL, JWT-сессии, realtime-каналы и файловое хранилище для аватаров.

## Миграция
Исходные файлы ещё не выгружены в этот репозиторий. Для завершения переноса нужно получить полный список файлов и их содержимое из исходного Floot-проекта, затем перенести их сюда и адаптировать инфраструктурные зависимости.

Не добавляйте реальные пароли, токены и API-ключи в Git. Используйте переменные окружения.
