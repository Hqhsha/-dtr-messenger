# DTR Phone Flip Android

Standalone Android APK wrapper for the Phone Flip game. The game is bundled in `app/src/main/assets/game.html` and saves progress in WebView local storage on-device.

## Build

GitHub Actions workflow: `.github/workflows/build-phoneflip-apk.yml` builds `app-debug.apk` and uploads it as the `DTR-Phone-Flip-debug-apk` artifact.
